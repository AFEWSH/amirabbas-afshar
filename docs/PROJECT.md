# Personal Portfolio

Owner: Amir Abbas Afshar. Public title: Full-Stack Developer | Backend-Focused. Primary specialization: PHP & Laravel.

## Goal and scope

A polished English portfolio for one developer: a single-page home, project index/details, article index/details, contact form, resume downloads, and a private Filament admin panel. The admin manages profile, links, skills, experience, education, projects, articles, messages, resumes, and small site settings.

Only administrator-entered facts appear as professional claims. Initial layout may use clearly labeled sample content; it must be replaced or hidden before publication.

## Non-goals

Public accounts, comments, custom page builder, complex search/filtering, multilingual content editing, email delivery, external APIs, multi-tenancy, and infrastructure such as Redis or queues.

## Delivery rule

Implement one requested phase at a time. Phase 0 produces planning documents only.
